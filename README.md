# Reference Service

Reference Service is a simple Spring Boot microservice responsible for generating
unique transaction reference numbers for a banking application.

This service is designed as an independent microservice and is consumed by the
Banking Application using Feign Client.

---

## 🚀 Features
- Generates unique transaction reference numbers
- Stateless and lightweight
- Designed for microservice architecture

---

## 🛠 Tech Stack
- Java 17
- Spring Boot
- Maven
